# Cờ Tướng Online

Chơi cờ tướng online miễn phí — không cần đăng nhập.

## Chạy local

**Yêu cầu:** Node.js 18+, MongoDB đang chạy tại localhost:27017

```bash
npm install
npm run dev
```

Mở http://localhost:3000

## Build production

```bash
npm run build && npm start
```

## Biến môi trường

| Tên | Mô tả |
|-----|-------|
| `MONGODB_URI` | MongoDB connection string |
