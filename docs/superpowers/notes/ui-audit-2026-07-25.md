# UI/UX Audit — co-tuong-online (2026-07-25)

## Critical bugs found

### A. Pointer cursor
- Many buttons lack `cursor: pointer` (verified by DOM scan):
  - `Chia sẻ` (share button in header)
  - Bottom action bar tabs (Lịch sử, Chat, Xem, Thêm) — `cursor: default`
  - Disabled `Gửi` chat button — `cursor: not-allowed` instead of `not-allowed` styling

### B. Captured pieces display
- `CapturedPieces` component renders `?` because `PIECE_CHARS` lookup is broken
- Worse: displays captured pieces even when game just started (empty initial state shows wrong info)
- Shows when board is at 0,0 — should be hidden until first capture

### C. Sidebar (Moves/Chat/Spectators)
- Still old design — emoji icons (📜💬👁⋯), cramped layout, no visual hierarchy
- No scroll area in chat, hard to read
- Move history has no current-move highlight cleanly
- Spectators list cramped, no real avatar
- Mobile bottom bar uses emoji + 4 tabs but feels cluttered

### D. Icons / visual polish
- "將" logo icon duplicated in multiple places (header + landing hero + footer)
- Theme picker dots (color circles) look like duplicate icons next to each other
- Loading spinner is just a border-circle, looks generic

### E. Mobile experience
- No bottom safe-area inset handling
- Hero section buttons wrap awkwardly
- Tournament card layout might overflow

### F. Game page flow
- "Play as opponent" / "Watch as spectator" modal pops up but uses emoji + plain text
- "You're muted" warning just a plain red text
- Result modal "Bạn Thắng!" still uses inline colors

### G. Accessibility
- No keyboard focus styles in some places
- Some color contrast may fail (need to test)
- Modals don't trap focus
